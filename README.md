# hyperliquid-scanner

RSI 극단 + 펀딩비 극단 반전 시그널 스캐너. GitHub Actions가 5분마다 `scan.js`를 실행하고, 신호 발생 시 ntfy로 알림을 보낸다. 설정은 `config.json`(파일 안 `_해설` 참고).

## signals.log

알림을 보낸 신호가 자동으로 한 줄씩 기록되는 파일 (워크플로가 커밋함). 용도 두 가지:

1. **중복 알림 방지** — 같은 봉에서 이미 알림 보낸 신호는 다시 안 보냄
2. **실전 기록** — 실제 발생한 신호를 계산기 백테스트 결과와 대조할 때 사용

직접 수정할 필요 없음. `SCANNER_FAIL` 줄은 전 종목 조회 실패(스캐너 장애) 기록.

## outcomes.log

매 실행마다 `signals.log`의 미결 신호를 캔들로 판정해 결과를 기록한다 (워크플로가 커밋). 컬럼: 판정시각 / 종목 / 방향 / 신호봉시각 / 결과(손절·목표·만료) / 진입 / 청산가 / R / 보유봉수.

- 알림 이후 마감된 봉부터 최대 48봉 판정. 한 봉에서 손절·목표가 모두 닿으면 손절 우선 (보수적).
- 48봉 안에 둘 다 안 닿으면 48번째 봉 종가로 `만료` 처리.
- 첫 실행 때 기존 `signals.log` 신호가 한꺼번에 소급 판정된다.

## 쿨다운

`config.json`의 `cooldown: true`이면, 같은 종목·같은 방향의 이전 신호가 아직 미결(`outcomes.log`에 결과 없음, 48봉 이내)일 때 새 신호 알림을 생략한다. 반대 방향 신호는 영향 없음. `false`로 끄면 이전 동작과 같다.
